# Open source

The smalt projects are open source.

| Project | Licence |
| --- | --- |
| smaltdb, and its plugins `@smaltdb/io`, `@smaltdb/external`, `@smaltdb/parquet` | MIT |
| smaltdf (`@smaltdb/df`) | MIT |
| smaltui · smaltbi · smaltkit | MIT |

The MIT licence lets you use, copy, change and ship the code, in open or closed projects, as long as the licence
notice comes with it. Each repository's `LICENSE` file is the authoritative text.

## Dependencies

smaltdb's core has no runtime dependencies. Where a plugin uses someone else's library, its README says so (for
example, `@smaltdb/parquet` decodes Parquet with hyparquet).

## Fonts

The brand uses Geist, Geist Mono and Martian Mono, all under the SIL Open Font License.

## The names and logos

The smalt names and logos identify the projects, so the [brand kit](/brand) sets out how to use them.
