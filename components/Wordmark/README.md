# Wordmark

The lockup: the Grain mark beside "smaltdb" in Martian Mono 600, with `alt` set in `primary`.

- The mark body uses `primary`; the chip uses `smalt-300` on light grounds and `smalt-100` on dark.
- The gap is half the mark's width, and the tagline aligns with the start of the word.
- For files, use the SVGs under `assets/Logos/`; this component is for live pages, where Martian Mono is loaded.
