# Button

A 44px-tall action button in two variants: primary (`primary` fill, `on-primary` text) and secondary (`surface` fill, `text`, a `text-3` outline that keeps the control edge above 3:1).

- One primary button per view.
- Focus shows a 2px `focus` ring with a 2px offset; never remove it.
- Labels are verbs in sentence case ("Get started", not "GET STARTED").
- The consumer provides the label and the handler; the minimum touch target is 44px.
