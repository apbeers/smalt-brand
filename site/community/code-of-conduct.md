# Code of conduct

smalties are the smalt of the earth. Here's how we treat each other.

- **Be kind.** Disagree with ideas, never with people. Assume good intent, and ask before you assume.
- **Make room.** Everyone was new once. Questions are welcome at every level, and so are people of every background.
- **Keep it smalty, not salty.** Irreverence is fine; mockery isn't. No harassment, insults, or unwelcome attention,
  in public or in private.
- **Credit others.** Say where ideas and code came from, including the tools that inspired ours.

This applies everywhere smaltworks happens: repositories, issues, pull requests, Discussions, and anywhere else you
represent the project.

## If something goes wrong

::: warning Reporting address coming soon
A private address for reporting conduct problems to the core team is being set up and will be listed here.
:::

The core team will read every report, keep it confidential, and may warn, remove content, or ban anyone who breaks
these rules.
