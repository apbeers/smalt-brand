smaltui + smaltbi · round 1

One family, three products

Shared with smaltdb: the Kiln neutrals, Geist and Martian Mono, the smalt… wordmark, and the Grain mark's language of a body plus a chip. What changes per product: the mark's shape, and optionally the chip's colour.

smaltdb

the engine · decided

A fast alternative database for the browser, written in TypeScript.

Small. Alternative. Fast.

smaltui

the workbench

A query workbench for smaltdb that runs entirely in the browser.

Object explorer, tabbed SQL editors, editable data grids and import tools, served as a static site.

smaltbi

the reports

Business intelligence in the browser, on smaltdb.

Model data, drag fields onto a canvas, and publish reports as static sites. SQL all the way down.
