# smaltworks logos

smaltworks makes the smalt family. Its mark, **Together**, is two L-shaped pieces that lock into one frame: separate tools, built to fit. The first piece is smalt (`#003399`), the second kiln orange (`kiln-500`, `#E5622F`).

| File | Use |
| --- | --- |
| `lockup.svg`, `lockup-on-dark.svg` | Mark + wordmark, outlined. The smaltworks name wherever it appears with the mark. |
| `wordmark.svg`, `wordmark-on-dark.svg` | Wordmark alone: `alt` in smalt, the rest in ink (`#151922` / `#E9EBF0`). |
| `together-mark.svg`, `together-mark-on-dark.svg` | The mark alone. Dark version: `#9DB4F5` and `#FF8A5C`. |
| `app-icon.svg` | Smalt tile with the mark knocked out. |
| `favicon-32.svg`, `favicon-16.svg` | Browser tabs. The same drawing at both sizes. |

The avatar for the GitHub organisation and the @smaltalk profiles is `social/smaltworks-avatar.png` (512 px, square; the sites round it themselves). The "A smaltworks project" endorsement is in `badges/`.

The `-on-dark` files are transparent with light ink, so they look blank in light previews.

Generated by `scripts/brand_assets.py`. Don't recolour, rotate, outline or add effects. Kiln orange is a fill only, never text.
